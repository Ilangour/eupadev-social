# EupaDev social posts

Daily Instagram posts for [EupaDev](https://github.com/EupaDev-hq/eupadev), presented by Eupa the cat.

`posts.json` holds the text, `render.mjs` and `audio.py` make the images and videos in `out/`, `calendar.json` says what goes out each day, and `publish.mjs` publishes it through GitHub Actions.

Voice: Piper with the SIWIS corpus (CC-BY 4.0). Music: generated by `audio.py`.
